# Flat Foot (Pes Planus) — Kaplan Orthopedic Lecture

**50-slide** widescreen PowerPoint for orthopedic surgery trainees, organized around Kaplan-style high-yield teaching on flatfoot / adult acquired flatfoot deformity (AAFD / PTTD).

## File

- [`Flat_Foot_Kaplan_Orthopedic_Lecture.pptx`](./Flat_Foot_Kaplan_Orthopedic_Lecture.pptx) — ready to present (16:9)

## Lecture map

| Block | Slides | Content |
|-------|--------|---------|
| Foundation | 1–11 | Objectives, anatomy, MLA, PTT, spring ligament, definition |
| Pathology | 12–25 | Classification, pediatric spectrum, AAFD stages I–IV, pathomechanics |
| Workup | 26–34 | History, exam, special tests, XR measurements, MRI/CT, DDx |
